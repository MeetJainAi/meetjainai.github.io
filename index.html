Chapter three

What I built

Three systems, and what they were actually for.

01

A pipeline that stopped
needing a person

Real-estate market data arrived from Zillow’s API in real time and had to become something a stakeholder could act on before it went stale.

Lambda handles extraction, S3 stages it across raw, refined and curated zones, Airflow on EC2 orchestrates the graph, Redshift warehouses it, and QuickSight puts it in front of the people deciding. Once it was running, nobody touched it.

  • S3
  • Airflow
  • EC2

A module library

Every team was provisioning the same resources slightly differently, and every difference was a future incident.

I built a versioned Terraform module library with documentation worth reading and a CI pipeline that tests infrastructure code before it reaches an account. The adoption was the hard part; the modules were the easy part.

Cloud spend is only mysterious until somebody makes every dollar traceable to an owner.

Lambda and CloudWatch stream utilisation into DynamoDB, tagging is automatically enforced so nothing is unattributable, QuickSight shows the trend, and a configurable alerting layer catches anomalous spend well before the bill arrives.
